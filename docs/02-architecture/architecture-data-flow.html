One Sentence

Habitat or Crafter emits observations; an ObsAdapter turns them into replay-compatible RGB, VGGT, or hybrid observations; the selected world-model encoder maps that observation to an embedding; the RSSM observes the embedding and actions; the world-model, behavior, and representation losses update one JAX/Flax parameter tree.

Runtime Topology

The launcher resolves an encoder string through encoder_registry. The resulting EncoderSpec owns four coupled facts: adapter, render resolution, observation shape, and Flax module class. That spec is passed into R2DreamerConfig; the agent instantiates the actual module on the JIT side.

VGGT Production Path

The production VGGT path is the JAX/Flax JAXVGGTFeatureExtractor. It consumes fixed (3, 518, 518) uint8 frames, maintains a streaming cache, and emits the readouts requested by the active variant.

Aggregator

Per frame: 1 camera + 4 register + 37*37 patches = 1374 tokens. Tokens are 2048-d internally; R2Dreamer readouts consume the 1024-d global half.

Heads

With compute_heads=True, the camera head emits a 9-d pose and the DPT head emits world points. The default adapter pools the dense point map to 37x37x3.

Cache

The JAX path uses a padded 3-tuple KV cache and static per-block budgets. The default launcher setup uses total budget 200000 and 8333 tokens per block.

Inside train_step

Once a sampled batch has the right observation shape, all encoder families converge into the same R2Dreamer training path.

obs batch
  -> encoder(obs) -> embed
  -> R2RSSM.observe(embed, actions, is_first) -> posterior stoch/deter
  -> R2RSSM prior(actions)                    -> prior logits
  -> feat = get_feat(stoch, deter)
  -> world_model_loss       # KL + reward + continue [+ decoder]
  -> behavior_loss          # detached imagination + lambda returns
  -> representation_loss    # Barlow Twins + replay-value
  -> total scaled loss
  -> jax.grad
  -> LaProp + AGC update
  -> slow critic EMA update

Contracts That Must Not Drift

Shape ownership

EncoderSpec.obs_shape, adapter buffer shape, and world-model module input checks must describe the same tensor. Shape drift should fail fast, not silently train.

Normalization

RGB is CHW and normalized for CNN use. VGGT and hybrid feature vectors are metric or learned features and are not divided by 255.

Episode boundaries

is_first must be truthful. The RSSM state and VGGT streaming cache depend on correct reset semantics.

VGGT token semantics

Do not feed the full 2048-d aggregator token where an encoder expects the 1024-d global stream or a pooled 3072-d vector.
