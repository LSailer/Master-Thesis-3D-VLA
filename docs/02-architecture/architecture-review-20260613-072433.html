Problem

Trainer has one public interface but a wide hidden interface: ordering, flushing, validation cadence, W&B, video, and hard-exit rules are coupled inside one implementation.

Solution

Deepen a training lifecycle module that owns run phases and finalization, while rollout, validation, and persistence become internal seams.

Wins
  • locality: finalization bugs concentrate
  • leverage: lifecycle tests replace smokes
  • overfit mode stops leaking
  • validation cadence is testable
