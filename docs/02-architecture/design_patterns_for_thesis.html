1 · How to read this

Each pattern carries one of three verdicts for this thesis:

  • ADOPT — concrete duplication smell already present in Master-Thesis-3D-VLA; the pattern pays its tax immediately.
  • MAYBE — useful once a second instance shows up. Don't introduce preemptively.
  • SKIP — well-known pattern that loses to "Hydra + a dataclass + a function" at thesis scale.
The single rule that drives every verdict — Karpathy's heuristic in A Recipe for Training Neural Networks: introduce an abstraction the second time you copy-paste, not the first. Most GoF patterns fail this test at thesis scale; a few survive.

2 · Classic design patterns (GoF + Fowler)

① Factory Method SKIP*

GoF Ch. 3 Head First Design Patterns 2e, Ch. 4

A function that returns a concrete object selected at runtime.

*Already free via hydra.utils.instantiate({"_target_": ...}). Writing a hand-rolled build_encoder() on top of Hydra is duplication, not abstraction. For three encoders, the registry you already have in launch/registries.py is enough.

② Builder SKIP

GoF Ch. 3 Bloch, Effective Java Item 2

Step-by-step assembly of a many-piece object. Bloch's threshold: 4+ params, some optional.

For DreamerV3 (encoder + RSSM + heads + actor + critic), a frozen @dataclass config + Hydra structured configs already covers this. Only revisit if you find yourself writing the same if cfg.aux is not None: agent.aux = ... glue in three places.

③ Adapter ADOPT

GoF Ch. 4 Fowler 2e

Bridge two incompatible interfaces without modifying either side.

You already have VGGTObsAdapter — formalize it: VGGT/UNITE output dict → flat embedding satisfying EncoderProtocol. The earlier report's plan to move adapters into vggt/adapter.py + shared/adapters/ is exactly this pattern.

④ Decorator (Env Wrappers) ADOPT

GoF Ch. 4 Gymnasium Wrapper

Add behavior by wrapping, not subclassing. The canonical RL idiom.

env = HabitatObjectNav(cfg)
env = FrameStack(env, k=4)
env = RewardShaping(env, success_bonus=10.0)
env = ActionRepeat(env, n=2)

Standardize on gymnasium.Wrapper subclasses — don't invent custom ones for things Gymnasium ships (FrameStackObservation, TimeLimit).

⑤ Observer / Callback MAYBE

GoF Ch. 5 PyTorch Lightning

Decouple "training loop" from things that observe it (loggers, checkpoints, eval).

Adopt once you have ≥3 cross-cutting concerns. trainer.py is at the threshold today: logging, checkpointing, manifest writing, eval — all mixed in. Extracting Callback objects is the cleanest way to shrink it (M3 in the migration plan).

⑥ Template Method SKIP

GoF Ch. 5

Parent defines the algorithm skeleton; subclasses fill in variable steps.

In Python, composition + a loss_fn callable is cleaner than inheritance. Most thesis code that reaches for Template Method should reach for Strategy instead — which you already have via the registry.

⑦ Command MAYBE

GoF Ch. 5

Encapsulate a request as a serializable object — queue it, log it, replay it.

@dataclass
class TrainCommand:
    cfg_path: str; seed: int; resume_from: str | None
    def execute(self): return train(load(self.cfg_path), self.seed, self.resume_from)
    def to_json(self): ...

Genuinely useful for SLURM audit trail — every job is replayable months later. Pairs with the MANIFEST pattern (§4).

⑧ Composite MAYBE

GoF Ch. 4

Treat individual and grouped objects uniformly via a shared interface.

class CompositeEncoder(Encoder):
    def __init__(self, parts): self.parts = parts
    def __call__(self, obs):
        return jnp.concatenate([p(obs) for p in self.parts], -1)

Worth it when you do multi-modal ablations (RGB-only vs RGB+3D) without touching the agent. Nested configs themselves are already Composite via OmegaConf — don't re-invent it for configs.

⑨ Memento (Checkpoint) ADOPT*

GoF Ch. 5

Externalize state for later restore, without violating encapsulation.

*This is ML checkpointing. Honour the convention: state_dict() / load_state_dict() in PyTorch, flax.training.orbax_utils in Flax. Don't roll your own. The migration step that splits trainer/checkpoint.py is the formal seam.

⑩ State SKIP

GoF Ch. 5

Behavior changes when internal state changes — looks like a class change.

For three modes (warmup / training / eval), a plain if wins. State pattern pays only at 5+ modes spread across many methods.

⑪ Null Object ADOPT

Fowler 2e — Introduce Special Case

A do-nothing object that satisfies the interface, killing if x is not None.

class NoOpLogger:
    def log_scalar(self, *a, **k): pass
    def log_video(self, *a, **k):  pass

Cheap, high payoff. Pair with IdentityEncoder as a no-3D-features ablation that needs no special-casing in the agent.

⑫ Fowler's refactoring moves ADOPT

Refactoring 2e

Day-to-day vocabulary, applied in small steps:

  • Extract Function — when train_step grows past one screen.
  • Extract Class — when Trainer accumulates checkpoint + logging + eval logic. Precursor to Callback ⑤.
  • Replace Conditional with Polymorphism — when an if encoder_name == ladder appears in more than one place. The smell is repeated switches.
  • Move Function — when a helper lives on Trainer but only touches Agent state.

3 · Python idioms for JAX/Flax

Language-specific patterns that don't appear in GoF, grouped by problem area.

A · Configuration & constants

IdiomSourceUse forVerdict
@dataclass(frozen=True, slots=True) Fluent Python 2e Ch. 5 Every config object. Pairs natively with Hydra structured configs. ADOPT
enum.StrEnum (3.11+) Effective Python 3e Ch. 6; Python enum HOWTO EncoderKind, AgentPhase — kills magic strings, autocompleted in editors. ADOPT
typing.Final PEP 591 Module-level constants — OBS_KEYS: Final[tuple[str, ...]] = (...). Static-checker hint only. MAYBE

B · State & pytrees (JAX/Flax)

IdiomSourceUse forVerdict
flax.struct.PyTreeNode Flax flax.struct docs; JAX pytree docs AgentState, WorldModelState. Plain @dataclass isn't a pytree — jit/grad/vmap choke. Mark static fields with struct.field(pytree_node=False). ADOPT · the cornerstone idiom
NamedTuple Fluent Python 2e Ch. 5; JAX pytree docs Lightweight Transition(obs, action, reward, done, next_obs) records in the replay buffer. Native pytree; zero registration. ADOPT

C · Control flow & resources

IdiomSourceUse forVerdict
@contextlib.contextmanager Effective Python 3e Item 82 Timing blocks, JAX device scopes, eval-mode toggles — anywhere you have try/finally pairs. ADOPT
Generators (yield) Effective Python 3e Items 43–47 Streaming buffer sampling, eval rollouts. But: prefer jax.lax.scan for inner training loops where JAX needs known shapes. ADOPT

D · Typing & interfaces

IdiomSourceUse forVerdict
typing.Protocol + @runtime_checkable Fluent Python 2e Ch. 13; PEP 544 The Encoder, Env, Buffer, Logger contracts (see §7 of Part I). @runtime_checkable only checks member existence, not signatures. ADOPT
Type aliases & NewType Fluent Python 2e Ch. 8; PEP 484/613 ObsBatch: TypeAlias = dict[str, jax.Array]. Reserve NewType for truly meaningful units (Embedding vs Logits) — overuse becomes noise. ADOPT (aliases) · MAYBE (NewType)

E · Reuse, composition & dispatch

IdiomSourceUse forVerdict
@functools.cache Fluent Python 2e Ch. 9 Heavy deterministic setup (HM3D scene metadata, pretrained-weight loading). Never on jit-traced functions or functions taking arrays — keys must be hashable. ADOPT
functools.partial Effective Python 3e Item 39 Optimizer/env factories: partial(optax.adamw, learning_rate=cfg.lr). Slatkin's explicit guidance: prefer over lambda for glue. ADOPT
__init_subclass__ Effective Python 3e Item 49; PEP 487 Self-registering encoders without a global registry dict. MAYBE — import-time side-effects are subtle; only adopt if the manual registry truly bothers you.
Mixins vs composition Fluent Python 2e Ch. 14 Default to composition in Flax codebases — mixins break pytree flattening if they add non-field attrs. Reserve mixins for truly stateless behavior. SKIP mixins · default to composition

4 · Reproducibility & experiment patterns

These are the patterns that turn a thesis codebase into something a reviewer (or future-you) can re-run and trust. Many already exist in Master-Thesis-3D-VLA in seed form — formalize them.

Seed-management pattern

Reseed every RNG that touches the run: Python random, NumPy, torch.manual_seed, torch.cuda.manual_seed_all, plus PYTHONHASHSEED and CUBLAS_WORKSPACE_CONFIG for cuBLAS determinism. PyTorch DataLoader workers each need their own worker_init_fn because they fork before seeds propagate. For JAX, thread an explicit PRNGKey through every call — never use a global. Source: PyTorch Reproducibility notes.

MANIFEST / Frozen-run pattern already partially implemented

On run start, write a MANIFEST.json recording git SHA, branch, dirty flag, full config, wandb id, SLURM job id, hostname, Python version, start time. On exit, append end-time + status. modules/r2dreamer/manifest.py already does this. The discipline that completes the pattern:

  • Refuse to start with git_dirty=True unless --allow-dirty is passed; record the override.
  • Pin pixi.lock into the run dir alongside the manifest.
  • tests/test_manifest.py already captures the schema as a contract — keep that test green through every refactor.

Source: Pineau et al., Improving Reproducibility in Machine Learning Research, JMLR 22(164), 2021; ML Reproducibility Checklist v2.0.

Hydra config-group ablation matrix

Orthogonal config groups: encoder/{vggt,unite,resnet}, world_model/{dreamer_v3,...}, task/{objectnav_hm3d}. A full sweep:

python train.py -m encoder=vggt,unite,resnet seed=0,1,2

Source: Hydra Multi-run docs, Configuring Experiments pattern.

One-config-per-table-row

Each row in your thesis results table → one named experiment config (configs/experiment/ablation_no_3d.yaml) that fully overrides the base. The config name is logged into MANIFEST and the wandb run tag → grep from caption to config to run.

Source: Huang et al., CleanRL, JMLR 23, 2022 — strongest published instantiation of one-variant-one-file.

SLURM patterns (bwUniCluster)

  • Requeue-on-preempt: #SBATCH --requeue + SIGTERM handler that flushes the latest checkpoint. SLURM Preemption docs.
  • Idempotent epoch: on startup, scan $RUN_DIR/checkpoints/ for the latest step and resume — config plus checkpoint must be sufficient. Never keep state only in RAM (the replay buffer is the killer; checkpoint it to disk shards every N steps).
  • Result file is the contract: every eval episode appends one JSON line to results.jsonl. Downstream plotting reads only that file — partial files are still valid input. Köster & Rahmann, Snakemake, Bioinformatics 2012 — files-as-edges is the entire philosophy.

Caption-the-SHA

Every figure/table caption in writing/ records the code/ commit SHA that produced it (e.g. Fig 4.2 (code@a1b2c3d)). Since code/ is public and writing/ is private, the SHA is the only legal cross-repo reference. The thesis CLAUDE.md already mandates this — fold the rule into a pre-commit hook that scans LaTeX for figure captions missing a SHA.

5 · Anti-patterns to call out

Anti-patternWhy it bitesSource
Notebook spaghetti Hidden kernel state, non-linear execution, no diffs. Allowed only for read-only plotting from a committed results.jsonl; never for training logic. Grus, I Don't Like Notebooks, JupyterCon 2018
Magic hyperparams LR = 3e-4 scattered across files. Cure: one Hydra config tree; no module-level numeric literals beyond mathematical constants. Karpathy, Recipe
Silent NaN "A misconfigured neural net will throw exceptions only if you're lucky." Cure: assert loss.isfinite() per step; log grad_norm / param_norm / actor_entropy / value_loss separately; fail fast. Karpathy, A Recipe for Training Neural Networks
Untracked manual rerun Re-running a stage outside the pipeline silently overwrites a logged number. Cure: every result file records its producing command + MANIFEST. Snakemake / DVC philosophy
Wandb-only metrics If wandb is the only place a number lives, you lose it when the project quota lapses. Always also write to disk. —
London-mockist tests over tensor code Mocks pin call patterns; numerical code mutates call patterns constantly. Stay Chicago-style: assert shape/dtype/finiteness/loss-decreases. Chicago vs London TDD

7 · Thesis reproducibility checklist (10 items)

  1. set_global_seed(seed) reseeds Python / NumPy / torch / torch.cuda + sets PYTHONHASHSEED, CUBLAS_WORKSPACE_CONFIG; called once at top of train.py and once per DataLoader worker.
  2. Every run dir contains MANIFEST.json + a copy of the resolved Hydra config + pixi.lock.
  3. Training refuses to start with git_dirty=True unless --allow-dirty is set; the flag is recorded in the manifest.
  4. One Hydra experiment config = one thesis-table row; config filename is logged to wandb tag + MANIFEST.
  5. Checkpoints written every N steps include replay-buffer state; resume from latest is a no-op if step matches.
  6. SLURM script uses --requeue and traps SIGTERM to flush checkpoint and MANIFEST end-status.
  7. Eval writes one JSON line per episode to results.jsonl; downstream plots read only that file.
  8. Every figure/table caption in the thesis includes the code/ commit SHA used to produce it.
  9. Numbers in the paper are pulled (via build script) from committed results.jsonl — never typed by hand.
  10. No notebooks in the training path. Notebooks allowed only for read-only plotting from results.jsonl; committed with cleared outputs.
