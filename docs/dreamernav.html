Paper Summary

DreamerNav

Learning-based autonomous navigation in dynamic indoor environments using world models

Shanks et al. 2025 Frontiers in Robotics and AI DreamerV3 Dynamic Obstacles

DreamerV3 + A* global planner + multimodal observations + curriculum training for navigation in warehouse environments with moving obstacles.

The Problem

Navigation in Dynamic Indoor Environments

Static planners fail

A* computes a path once at episode start. If a moving obstacle blocks the path later, the robot collides — no replanning.

Vision-only methods explore too much

NoMaD and ViNT take large detours or conservative avoidance. They don't build an internal model of how the environment changes.

Dynamic environments

Warehouses, hospitals, offices — moving people, forklifts, shifting objects. The agent must react in real-time while still following a global plan.

Key insight: Combine a global A* path (knows the static layout) with a DreamerV3 world model (imagines future dynamics) for reactive local planning.

Hybrid global-local planning

  • > A* computes the global path on the static map at episode start
  • > DreamerV3 handles local dynamic obstacle avoidance via imagination
  • > Subgoals along A* path guide the agent — updated as agent progresses

POMDP Formulation

  • > S — stochastic state (obstacles, robot pos)
  • > H — deterministic history (past obs + actions)
  • > O — images + vectors (partial observability)
  • > A — discrete: forward, left, right, no-movement

World Model

RSSM: Recurrent State-Space Model

Encoder (enc)

Maps raw observation x_t (occ maps, depth, vectors) into stochastic latent state z_t. Compresses high-dimensional input into compact representation.

Dynamics Network (dyn)

Predicts next latent z_{t+1} from current (z_t, h_t, a_t). This is the "imagination" — predicts future without acting in the real environment.

Decoder (dec)

Reconstructs observation x_t from z_t. Not used for decisions — trains the encoder to learn useful representations via reconstruction loss.

Reward Network (rew)

Predicts immediate reward r_t from z_{t+1}. Enables the actor to evaluate imagined trajectories without real environment interaction.

Recurrent state h_t: Deterministic, aggregates history (size 2048). Stochastic state z_t: Compressed features (32 discrete, 32 stochastic). Together they form the model state s_t = {h_t, z_t}.

Observations

What the Agent Sees

Image Observations

Occupancy Map (2 layers)

  • Layer 1: agent position (blue), trajectory (indigo), orientation (coral), static obstacles (black), dynamic obstacles (red), their trajectories (orange), POIs (green)
  • Layer 2: A* path (violet) overlaid on static map, goal (yellow)

Egocentric Depth Image

From robot's camera. Perceives distance to nearby objects for real-time obstacle avoidance.

Subgoals are dynamically updated along the A* path as the agent progresses. The agent always has a local target to aim for.

Actor-Critic

Policy and Value Learning

Actor (Policy)

Samples actions from the policy: a_t ~ pi(a_t | z_t)

Trained to maximize lambda-returns via REINFORCE + entropy regularization (same as DreamerV3).

Imagination horizon: H = 15 steps

Entropy coefficient: 0.0003

Critic (Value)

Estimates expected return: v(z_t) = E[sum of discounted rewards | z_t]

Trained via TD-learning on lambda-returns (lambda = 0.95).

Discount factor: gamma = 0.996997

Slow critic EMA for stability.

Key difference from standard DreamerV3: Actor-critic gradients do NOT flow into the world model. This prevents overly optimistic model updates — the world model stays grounded in real data.

Advancement criteria

Success rate ≥ 0.75 over last 20 episodes for 20 consecutive episodes.

Training setup

  • NVIDIA Isaac Sim (warehouse)
  • 4 dynamic obstacles (cuboids = workers)
  • 8 parallel agents
  • 495K policy steps, ~24.8 hours
  • Single NVIDIA 4090 GPU

Start easy, gradually increase difficulty. Short goals with large success radius first, then farther goals with tighter radius. Level 6 is the full task.

Qualitative Analysis

Three Navigation Scenarios

Scenario 1: Clear Path

All methods navigate well. DreamerNav takes minor detours to avoid dynamic obstacles, still succeeds. A* takes shortest path. NoMaD and ViNT also succeed.

All succeed

Scenario 2: Obstacle on Path

Dynamic obstacle appears on the A* path. DreamerNav deviates slightly and returns. ViNT succeeds with conservative avoidance. NoMaD fails (overly conservative). A* succeeds.

DreamerNav NoMaD fails

Scenario 3: Confined + Dynamic

All methods struggle in tight spaces with multiple dynamic obstacles. DreamerNav makes limited adjustments but still collides. Highlights fundamental difficulty.

All struggle

Strength: Adapts trajectory close to the optimal path in real-time. Weakness: Confined spaces with aggressive dynamics remain challenging.

Relevance

DreamerNav vs Our Setup

DreamerNav

  • Isaac Sim (single warehouse)
  • Dynamic obstacles (moving cuboids)
  • A* global path as observation
  • Occupancy map + depth + vectors
  • 7 dense reward components
  • 6-level curriculum
  • PyTorch (DreamerV3 NS512)
  • 495K steps, ~25 hours on 4090

Our Work

  • Habitat (HM3D, 145+ scenes)
  • Static environments (for now)
  • No global planner — pure RL
  • RGB only (+ future 3D features)
  • Sparse or geodesic-delta reward
  • No curriculum (yet)
  • JAX (R2-Dreamer)
  • 2.4M+ steps on SLURM cluster

Takeaways: DreamerNav shows curriculum + dense rewards + privileged observations (maps, A* path, vectors) make DreamerV3 work for navigation. Our setup is harder: no map, no path planner, sparse reward, diverse scenes.

Summary

Key Takeaways

1

World models work for navigation

DreamerV3's RSSM can learn warehouse navigation from pixels + vectors, outperforming vision-only methods (NoMaD, ViNT) and static planners (A*).

2

Privileged observations matter a lot

The agent gets a global occupancy map, an A* path, heading vectors, and distance to subgoals. This is far more information than just RGB.

3

Dense reward + curriculum = stable training

7 reward components and 6 difficulty levels produce consistent learning in ~25 hours. Contrast with our sparse-reward setup where 2.4M steps showed no learning.

4

Single environment limits generalization

Trained and tested in one warehouse layout. Real-world transfer shown on 2 quadrupeds (proof-of-concept) but no multi-scene generalization.

5

Dynamic obstacle avoidance is the main contribution

The world model imagines how obstacles will move and plans around them. Static navigation alone doesn't need a world model — A* suffices.
