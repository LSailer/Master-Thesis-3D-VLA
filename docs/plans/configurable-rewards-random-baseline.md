# Plan: Configurable Rewards + Random Baseline Module

> Source PRD: #61

## Architectural decisions

- **Reward parameters**: `step_penalty` and `success_bonus` live in `DreamerConfig` / `R2DreamerConfig` dataclasses, consumed by `HabitatObjectNavEnv._compute_reward()`
- **GOAL_RADIUS = 0.2**: Stays hardcoded as module-level constant in `habitat.py`
- **Baselines module**: `modules/baselines/` — standalone, no model dependencies (no JAX, no R2Dreamer imports)
- **Output format**: Per-episode CSV + aggregate JSON in `output/baselines/random-l1/`
- **Curriculum**: Reads `data/curriculum/level1_1house_1goal.json`, runs `eval` split (834 episodes)

---

## Phase 1: Configurable reward parameters

### What to build

Add `step_penalty: float = -0.01` and `success_bonus: float = 10.0` to both config dataclasses. Update `_compute_reward()` to use them. Update the STOP action branch to also apply `step_penalty`. This is a pure config+env change — no new modules, no new scripts.

### Files to modify

- `modules/dreamerv3/configs.py` — add fields
- `modules/r2dreamer/config.py` — add fields
- `modules/envs/habitat.py` — update `_compute_reward()` and STOP action reward

### Acceptance criteria

- [ ] `DreamerConfig.step_penalty == -0.01` and `DreamerConfig.success_bonus == 10.0`
- [ ] `R2DreamerConfig.step_penalty == -0.01` and `R2DreamerConfig.success_bonus == 10.0`
- [ ] `_compute_reward()` uses `self._cfg.success_bonus` instead of hardcoded `10.0`
- [ ] `_compute_reward()` adds `self._cfg.step_penalty` to every step (including STOP)
- [ ] Existing tests still pass (reward behavior unchanged with defaults except for new step penalty)

## Phase 2: Random baseline module + SLURM script

### What to build

Create `modules/baselines/` with a `random_agent.py` script that:
1. Loads L1 curriculum eval episodes via `HabitatObjectNavEnv`
2. Runs uniform-random actions for all 834 episodes
3. Collects per-episode metrics (steps, reward, success, SPL, action counts)
4. Saves per-episode CSV and aggregate JSON to `output/baselines/random-l1/`
5. Prints summary to stdout

Also create a SLURM sbatch script to run it on the cluster.

### Files to create

- `modules/baselines/__init__.py`
- `modules/baselines/random_agent.py`
- `modules/baselines/scripts/slurm/run_random_baseline.sbatch`

### Acceptance criteria

- [ ] `python modules/baselines/random_agent.py --curriculum_path data/curriculum/level1_1house_1goal.json --output_dir output/baselines/random-l1/` runs to completion
- [ ] Produces `output/baselines/random-l1/episodes.csv` with columns: episode, scene, category, steps, reward, success, spl, stop_pct, forward_pct, left_pct, right_pct
- [ ] Produces `output/baselines/random-l1/summary.json` with aggregate SR, SPL, mean reward, mean steps, action distribution, episode count
- [ ] Action distribution is approximately uniform (~25% each)
- [ ] SLURM script runs on dev_gpu_h100, completes in <30min
