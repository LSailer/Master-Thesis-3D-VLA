DreamerV3 critic return: numbers intuition

1. Plain discounted return $R_t$

The paper defines the ideal infinite-horizon return as:

$$R_t = \sum_{\tau=0}^{\infty} \gamma^\tau r_{t+\tau}$$

Expanded:

$$R_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \gamma^3 r_{t+3} + \cdots$$

Key point: the exponent is the distance from now. Reward 10 steps after $t$ gets weight $\gamma^{10}$.

4. DreamerV3 cannot imagine forever

DreamerV3 imagines only a short horizon, for example $T=16$. Therefore it uses the critic's value estimate at the end.

The paper uses the bootstrapped $\lambda$-return:

$$R_t^\lambda = r_t + \gamma c_t \left((1-\lambda)v_t + \lambda R_{t+1}^\lambda\right)$$
$$R_T^\lambda = v_T$$
  • $r_t$: reward predicted by the world model now
  • $\gamma$: discount for future rewards
  • $c_t$: continuation flag; if episode ends, future is cut off
  • $v_t$: critic's current estimate of future return
  • $\lambda$: how much to use multi-step imagined rewards instead of immediately trusting the critic

5. Numeric $\lambda$-return example

Use:

$$\gamma=0.997,\quad \lambda=0.95,\quad c_t=1$$

Imagined rewards and final critic value:

$$r_0=1,\quad r_1=2,\quad r_2=0,\quad r_3=5,\quad v_4=10$$

Compute backward:

$$R_4^\lambda = v_4 = 10$$
$$R_3^\lambda = 5 + 0.997 \cdot 10 = 14.970$$
$$R_2^\lambda = 0 + 0.997 \cdot 14.970 = 14.925$$
$$R_1^\lambda = 2 + 0.997 \cdot 14.925 = 16.880$$
$$R_0^\lambda = 1 + 0.997 \cdot 16.880 = 17.829$$

This simplified version acts like $\lambda=1$ because we only used the final bootstrap. With $\lambda<1$, each step also mixes in the local critic value $v_t$.

6. Full $\lambda<1$ example with local values

Now include local critic estimates:

$$v_0=12,\quad v_1=11,\quad v_2=9,\quad v_3=8,\quad v_4=10$$

With $\lambda=0.95$, each step uses:

$$(1-\lambda)v_t + \lambda R_{t+1}^\lambda = 0.05v_t + 0.95R_{t+1}^\lambda$$

Backward calculation:

$$R_4^\lambda = 10$$
$$R_3^\lambda = 5 + 0.997(0.05\cdot 8 + 0.95\cdot 10) = 14.870$$
$$R_2^\lambda = 0 + 0.997(0.05\cdot 9 + 0.95\cdot 14.870) = 14.536$$
$$R_1^\lambda = 2 + 0.997(0.05\cdot 11 + 0.95\cdot 14.536) = 16.314$$
$$R_0^\lambda = 1 + 0.997(0.05\cdot 12 + 0.95\cdot 16.314) = 17.048$$

7. Critic loss feeling

The critic predicts a distribution over possible returns:

$$v_\psi(R_t \mid s_t)$$

Training target is the computed $\lambda$-return, e.g.:

$$R_0^\lambda = 17.048$$

The loss is negative log-likelihood:

$$\mathcal{L}(\psi) = -\sum_{t=1}^T \ln p_\psi(R_t^\lambda \mid s_t)$$

Meaning: if the critic assigns high probability to the target return, loss is low. If it assigns low probability, loss is high.
