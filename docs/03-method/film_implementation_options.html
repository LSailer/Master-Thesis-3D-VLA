\subsection{Encoder-to-World-Model Feature Fusion}
\label{sec:method-film-fusion}

The InfiniteVGGT encoder emits two heterogeneous streams: a $37 \times 37 \times 3$
world-point grid and a 9-dimensional learned camera-pose embedding. A naive
flatten-and-project fusion lets the spatial stream dominate the gradient signal,
since the pose contributes only $0.22\%$ of input dimensions and is therefore
effectively ignored by the world-model encoder. We replace this with Feature-wise
Linear Modulation (FiLM)~\cite{perez_film_2018}, in which a small MLP maps the
conditioning signal to per-channel scale and shift parameters
$\gamma_c = f_c(\mathrm{pose})$ and $\beta_c = h_c(\mathrm{pose})$
(Equation~1 of~\cite{perez_film_2018}) that apply the per-channel affine
transformation
$\mathrm{FiLM}(x_c \mid \gamma_c, \beta_c) = \gamma_c \cdot x_c + \beta_c$
(Equation~2 of~\cite{perez_film_2018}) to the world-point feature map. This makes
the pose contribution \emph{multiplicative} on the spatial features rather than
additive at the input: the world model cannot ignore the pose without explicitly
zeroing $\gamma$, which has a non-trivial gradient cost. We initialize
$\gamma = 1$ and $\beta = 0$ following the RT-1 convention~\cite{brohan_rt1_2023}
so that the encoder reduces exactly to the non-modulated baseline at step zero,
and we monitor the per-stream gradient ratio
$\| \partial \mathcal{L} / \partial \mathrm{pose} \| \,/\, \| \partial \mathcal{L} / \partial \mathrm{wp} \|$
during training as a diagnostic for modal balance.

Problem (recap from issue #109)

Two streams enter the world-model encoder:

  • A — VGGT world points: shape (B, 37, 37, 3) = 4107 dims, a dense 3D feature grid.
  • B — VGGT camera pose embedding: shape (B, 9), a learned low-dim signal.
  • Target: a 1024-dim embedding consumed by the RSSM posterior/prior heads.

Currently VGGTEncoder (modules/r2dreamer/networks.py:414-432) flattens both into a 4116-dim vector and runs a single Dense(4116→1024). Because B is only 0.22% of the input dimensions, gradients with respect to B are tiny relative to A's — the pose stream is effectively ignored.

FiLM fixes this by making B's contribution multiplicative on A: B cannot be ignored without zeroing the modulation parameters γ, which has a non-trivial gradient cost.

γ, β = fFiLM(B)    # tiny MLP on the 9-dim signal
y = γ ⊙ x + β    # affine modulation of the spatial stream x

Original paper: Perez et al., FiLM: Visual Reasoning with a General Conditioning Layer, AAAI 2018 (arXiv:1709.07871). Survey: Dumoulin et al., Feature-wise transformations, Distill 2018 (distill.pub).

Codebase integration (shared across all options)

Every variant below replaces the body of VGGTEncoder and follows the same plumbing pattern. The contract on either side is fixed: input is the flat 4116-dim observation, output is a 1024-dim embedding for the RSSM. Five touch points:

  1. New Flax module in modules/r2dreamer/networks.py (e.g. FiLMEncoder_v1 … v5).
  2. Wrapper in modules/r2dreamer/launch/encoders.py.
  3. Registry key in modules/r2dreamer/launch/registries.py (e.g. "vggt_film_v1").
  4. Config fields in modules/r2dreamer/config.py (channels, depth, init scale).
  5. Shape test mirroring test_vggt_encoder.py::test_output_shape; add gradient-norm probe.

Splitting the flat 4116 vector inside the module is one line: 

wp = obs[:, :4107].reshape(-1, 37, 37, 3)   # spatial stream A
pose = obs[:, 4107:]                         # conditioning B (9 dims)

For all five options, log per-stream gradient L2 norms (‖∂L/∂wp‖ vs ‖∂L/∂pose‖) during early training as a sanity check that B is actually contributing — this is the same diagnostic the issue's last TODO calls for.

Five implementation options
  1. Vanilla FiLM (per-channel, single layer) — minimal, RT-1-style baseline
  2. Stacked Conv-FiLM — multi-block modulation, hierarchical features
  3. AdaLN-Zero Transformer — DiT-style, zero-init, per-block gates
  4. Sigmoid-gated FiLM with hypernet generator — bounded modulation, richer conditioner
  5. Spatial-aware FiLM (tile + per-token γ,β) — preserves "where" in the conditioner

1. Vanilla FiLM (per-channel, single layer)

simplest ~1 day closest to RT-1

A direct port of Perez et al. 2018: one conv stem, one FiLM layer, pool, project.

Architecture

obs (B, 4116) │ ├── split ─────────────► pose (B, 9) ──┐ │ │ └── reshape (B, 37, 37, 3) │ │ │ Conv 3×3, 3 → D=64, RMSNorm, SiLU │ │ x : (B, 37, 37, 64) │ │ │ ┌───────── FiLM ◄──── MLP_film(pose) → (γ, β) ∈ ℝ²ᴰ │ y = γ ⊙ x + β (broadcast over H, W) │ Global-avg-pool → (B, 64) Dense 64 → 1024 embed (B, 1024)
γ, β = MLP(pose; hidden=128) ∈ ℝ²ᴰ   (D=64)
yb,h,w,c = γb,c · xb,h,w,c + βb,c

Flax skeleton

class FiLMEncoder_v1(nn.Module):
    embed_dim: int = 1024
    channels: int = 64
    film_hidden: int = 128

    @nn.compact
    def __call__(self, obs):
        wp   = obs[:, :4107].reshape(-1, 37, 37, 3)
        pose = obs[:, 4107:]

        x = nn.Conv(self.channels, (3, 3), padding="SAME")(wp)
        x = nn.RMSNorm()(x)
        x = nn.silu(x)

        h = nn.Dense(self.film_hidden)(pose); h = nn.silu(h)
        gb = nn.Dense(2 * self.channels,
                      kernel_init=nn.initializers.zeros)(h)         # ← zero-init
        gamma, beta = jnp.split(gb, 2, axis=-1)
        gamma = 1.0 + gamma                                         # identity at init

        x = gamma[:, None, None, :] * x + beta[:, None, None, :]
        x = jnp.mean(x, axis=(1, 2))                                # global-avg-pool
        return nn.Dense(self.embed_dim, name="proj")(x)

Pros

  • Smallest surface area; cleanest A/B test against the current VGGTEncoder.
  • Identity-initialised: behaviour at step 0 ≈ pure-A encoder; pose contribution learns in.
  • Cheap (~10k extra params); won't move VRAM budget.

Cons

  • Single point of modulation: B can only steer the post-conv features once.
  • Per-channel only — pose direction info is broadcast across the spatial grid.
  • If the conv stem destroys 3D structure, FiLM can't recover it.

Init recipe

Zero-init the final Dense of MLP_film; use γ = 1 + Δγ so the block is identity at step 0 (RT-1 convention). Use RMSNorm not LayerNorm to match the existing R2Encoder style.

2. Stacked Conv-FiLM (RT-1 lite)

RT-1 precedent ~2 days hierarchical

Mirror the existing R2Encoder conv stack and inject FiLM after every block, so pose modulates low- and high-level features independently.

Architecture

obs ──► pose (B, 9) ──► MLP_film ──► [γ¹,β¹, γ²,β², γ³,β³, γ⁴,β⁴] (per-block params) │ └── reshape (B, 37, 37, 3) │ ConvBlock 3→32 ──► FiLM¹ ──► MaxPool → (B, 18, 18, 32) ConvBlock 32→64 ──► FiLM² ──► MaxPool → (B, 9, 9, 64) ConvBlock 64→128 ──► FiLM³ ──► MaxPool → (B, 4, 4, 128) ConvBlock 128→256──► FiLM⁴ ──► AvgPool → (B, 256) Dense 256 → 1024

Each ConvBlock = Conv3×3 + RMSNorm + SiLU, identical to R2Encoder. FiLMi applies block-specific γi, βi per-channel. The pose MLP has a single hidden layer and emits one big vector that is split into the four (γ, β) pairs.

Flax skeleton

class FiLMEncoder_v2(nn.Module):
    embed_dim: int = 1024
    chans: tuple = (32, 64, 128, 256)
    film_hidden: int = 256

    @nn.compact
    def __call__(self, obs):
        wp, pose = obs[:, :4107].reshape(-1,37,37,3), obs[:, 4107:]

        # one shared MLP emits all (γ, β) pairs
        h = nn.silu(nn.Dense(self.film_hidden)(pose))
        all_gb = nn.Dense(2 * sum(self.chans),
                          kernel_init=nn.initializers.zeros)(h)
        splits = jnp.cumsum(jnp.array(list(self.chans) * 2))[:-1]
        params = jnp.split(all_gb, splits, axis=-1)
        gammas, betas = params[:len(self.chans)], params[len(self.chans):]

        x = wp
        for i, c in enumerate(self.chans):
            x = nn.Conv(c, (3, 3), padding="SAME")(x)
            x = nn.RMSNorm()(x); x = nn.silu(x)
            g = 1.0 + gammas[i][:, None, None, :]
            b = betas[i][:, None, None, :]
            x = g * x + b
            if i < len(self.chans) - 1:
                x = nn.max_pool(x, (2, 2), strides=(2, 2))
        x = jnp.mean(x, axis=(1, 2))
        return nn.Dense(self.embed_dim)(x)

Pros

  • Pose modulates feature hierarchies separately — early layers (textures) and late layers (semantics).
  • Direct empirical analogue: RT-1 uses exactly this pattern (FiLM-ed EfficientNet-B3) on robot policies.
  • Reuses R2Encoder's block style — visually consistent with the rest of the codebase.

Cons

  • 4× the FiLM parameters of option 1; 4× the things that can mis-init.
  • Multi-stage pooling discards spatial structure quickly — may underperform on a 37×37 grid that is already small.
  • Harder to debug per-layer contributions without instrumentation.

Init recipe

Same zero-init on the final Dense of the shared FiLM MLP; γ = 1 + Δγ everywhere. Optionally add per-block learnable scalar αi initialised to 1 in front of FiLMi so deeper modulations can be turned off if not useful.

3. AdaLN-Zero Transformer

DiT-style ~3 days strongest model

Treat the 37×37 grid as 1369 tokens; stack transformer blocks with AdaLN-Zero modulation conditioned on pose. Per-block residual gates make initialisation safe.

Architecture

wp (B, 37, 37, 3) │ Conv 1×1: 3 → D=128 (token stem) │ flatten → tokens (B, 1369, 128) │ + 2D learned positional embedding │ ┌───┴─────────────────────────────────────┐ │ N = 4 × AdaLN-Zero Transformer block │ ◄──── pose (B, 9) → MLP → (γ, β, α) × 2 per block │ │ │ y = x + α_attn ⊙ MSA(LN_γ_attn,β_attn(x)) │ y = y + α_mlp ⊙ MLP(LN_γ_mlp,β_mlp (y)) └─────────────────────────────────────────┘ │ mean-pool tokens → (B, 128) Dense 128 → 1024

Each block contains a Multi-Head Self-Attention (MSA) and an MLP, each preceded by a LayerNorm whose affine parameters are replaced by (γ, β) from pose, and followed by a learned output gate α. Zero-init the final Dense of the modulation MLP so γ → 0, β → 0, α → 0 — every block starts as identity. This is the AdaLN-Zero recipe from DiT (Peebles & Xie 2022).

γm, βm, αm = MLPm(pose),   m ∈ {attn, mlp}
h = h + αattn ⊙ MSA(LN(h) · (1+γattn) + βattn)
h = h + αmlp ⊙ MLP(LN(h) · (1+γmlp) + βmlp)

Flax skeleton (one block; stack N of them)

class AdaLNZeroBlock(nn.Module):
    dim: int = 128; heads: int = 4; mlp_ratio: int = 4

    @nn.compact
    def __call__(self, x, cond):
        gb = nn.Dense(6 * self.dim,
                      kernel_init=nn.initializers.zeros)(nn.silu(cond))
        g_a, b_a, a_a, g_m, b_m, a_m = jnp.split(gb, 6, axis=-1)

        h = nn.LayerNorm(use_bias=False, use_scale=False)(x)
        h = h * (1 + g_a[:, None, :]) + b_a[:, None, :]
        h = nn.MultiHeadDotProductAttention(num_heads=self.heads,
                                            qkv_features=self.dim)(h, h)
        x = x + a_a[:, None, :] * h

        h = nn.LayerNorm(use_bias=False, use_scale=False)(x)
        h = h * (1 + g_m[:, None, :]) + b_m[:, None, :]
        h = nn.Dense(self.dim * self.mlp_ratio)(h); h = nn.gelu(h)
        h = nn.Dense(self.dim)(h)
        return x + a_m[:, None, :] * h

Pros

  • Strongest empirical track record — DiT, MaskDiT, RIN, large generative VLAs.
  • Zero-init + residual gate makes step-0 behaviour exactly the no-FiLM baseline; safe to drop in.
  • Per-block per-token attention preserves 3D spatial structure of the VGGT grid.

Cons

  • 1369 tokens × 4 blocks of self-attention is ~the heaviest of these five options (≈ 5–8M params, depending on D, heads).
  • More moving parts: positional encoding, head count, MLP ratio — each is a new hyperparameter.
  • Risk of being too expressive for HM3D rollout count; needs careful regularisation.

Init recipe

Always zero-init the final Dense of the per-block modulation MLP. Without that, AdaLN with γ=0 silently kills the signal. Pair with weight decay 1e-4 on attention layers; LR warmup (1k steps) is more important here than for options 1, 2, 4.

4. Sigmoid-gated FiLM with hypernet generator

bounded ~1.5 days richer conditioner

Vanilla FiLM but with bounded multiplicative gates and a deeper conditioner. Optional auxiliary loss reconstructs pose from the embedding to force B contribution.

Architecture

wp ──► Conv stem (3 → D=96) → x : (B, 37, 37, 96) pose (B, 9) ──► HyperNet (3-layer MLP, hidden 256, residual) │ ├──► γ_logits ──► σ(·) ∈ (0, 1) (gate) ├──► β ∈ ℝᴰ (shift) │ y = γ ⊙ x + β (broadcast) ↓ Dense(D → 1024) ↓ ┌── (optional) aux head: Dense(1024 → 9) reconstructs pose
γ = σ(Wγ · h(pose))   ∈ (0, 1)
β = Wβ · h(pose)
y = γ ⊙ x + β
L = LRSSM + λ · ‖pose − Dec(embed)‖²   (optional, λ = 0.1)

Flax skeleton

class FiLMEncoder_v4(nn.Module):
    embed_dim: int = 1024
    channels: int = 96
    hyper_hidden: int = 256
    aux_pose_recon: bool = True

    @nn.compact
    def __call__(self, obs):
        wp   = obs[:, :4107].reshape(-1, 37, 37, 3)
        pose = obs[:, 4107:]

        x = nn.Conv(self.channels, (3, 3), padding="SAME")(wp)
        x = nn.RMSNorm()(x); x = nn.silu(x)

        # 3-layer hypernet with one residual connection
        h0 = nn.silu(nn.Dense(self.hyper_hidden)(pose))
        h1 = nn.silu(nn.Dense(self.hyper_hidden)(h0)) + h0
        gl = nn.Dense(self.channels,
                      kernel_init=nn.initializers.zeros)(h1)
        bt = nn.Dense(self.channels,
                      kernel_init=nn.initializers.zeros)(h1)
        gamma = nn.sigmoid(gl)            # bounded ∈ (0, 1), starts at 0.5
        beta  = bt

        y = gamma[:, None, None, :] * x + beta[:, None, None, :]
        y = jnp.mean(y, axis=(1, 2))
        embed = nn.Dense(self.embed_dim)(y)

        if self.aux_pose_recon:
            pose_hat = nn.Dense(9)(embed)
            self.sow("aux", "pose_hat", pose_hat)   # consumed by loss
        return embed

Pros

  • Sigmoid bounds γ ∈ (0, 1): no risk of multiplicative explosion when pose is OOD.
  • Hypernet (3 layers, residual) gives the small B stream more capacity to shape modulation.
  • Optional pose-reconstruction head is a strong forcing function: the embedding must retain B information.

Cons

  • γ ∈ (0,1) means feature magnitudes can only shrink, not grow — sometimes that's wrong.
  • Auxiliary loss needs a tuned weight λ; too high and the embedding becomes a pose autoencoder.
  • Bigger hypernet on a 9-dim input can overfit on small replay buffers.

Init recipe

Zero-init the γ and β heads so γ = σ(0) = 0.5 and β = 0 at start (slight signal attenuation, no bias). If you want strict identity-init use y = (1 + γ) ⊙ x + β with γ from a tanh head instead, but the σ form has nicer gradient properties.

5. Spatial-aware FiLM (tile + per-token γ, β)

geometry-preserving ~2 days if pose has direction

Don't broadcast pose across the grid — let it modulate different spatial locations differently. Useful if the 9-dim pose embedding has any directional / extrinsic structure.

Architecture

wp (B, 37, 37, 3) pose (B, 9) │ │ │ ├── tile to (B, 37, 37, 9) │ ├── add 2D Fourier pos-enc (B, 37, 37, P) │ │ │ └── Conv 1×1 ((9 + P) → 2D) ──► (γ_hw, β_hw) │ shape (B, 37, 37, 2D) Conv 3×3, 3 → D │ y_{b,h,w} = γ_{b,h,w} ⊙ x_{b,h,w} + β_{b,h,w} (per-token!) │ Conv 3×3, D → D, RMSNorm, SiLU Global-avg-pool → Dense(D → 1024)

Pose is tiled across the 37×37 grid and concatenated with positional encoding before predicting γ, β. The result is per-token modulation: pose can attenuate one corner of the grid and amplify another. This matters if the pose embedding contains any rotation-/translation-like signal that should map to specific image regions (e.g. "goal is in front-right").

zh,w = concat(pose, posenc(h, w))
γh,w, βh,w = Conv1×1(z)
yb,h,w,c = γb,h,w,c · xb,h,w,c + βb,h,w,c

Flax skeleton

class FiLMEncoder_v5(nn.Module):
    embed_dim: int = 1024
    channels: int = 96
    pos_freqs: int = 8

    @nn.compact
    def __call__(self, obs):
        wp   = obs[:, :4107].reshape(-1, 37, 37, 3)
        pose = obs[:, 4107:]

        # 2D Fourier positional grid (37, 37, 4 * pos_freqs)
        ys, xs = jnp.linspace(-1, 1, 37), jnp.linspace(-1, 1, 37)
        gy, gx = jnp.meshgrid(ys, xs, indexing="ij")
        freqs = 2.0 ** jnp.arange(self.pos_freqs)
        pe = jnp.stack([jnp.sin(gy[..., None] * freqs * jnp.pi),
                        jnp.cos(gy[..., None] * freqs * jnp.pi),
                        jnp.sin(gx[..., None] * freqs * jnp.pi),
                        jnp.cos(gx[..., None] * freqs * jnp.pi)],
                        axis=-1).reshape(37, 37, -1)

        # tile pose, concat with posenc, broadcast batch
        pose_tiled = jnp.broadcast_to(pose[:, None, None, :],
                                       (pose.shape[0], 37, 37, 9))
        pe_b       = jnp.broadcast_to(pe[None],
                                       (pose.shape[0], 37, 37, pe.shape[-1]))
        z = jnp.concatenate([pose_tiled, pe_b], axis=-1)

        # spatial stem
        x = nn.Conv(self.channels, (3, 3), padding="SAME")(wp)
        x = nn.RMSNorm()(x); x = nn.silu(x)

        # per-token (γ, β)
        gb = nn.Conv(2 * self.channels, (1, 1),
                     kernel_init=nn.initializers.zeros)(z)
        gamma, beta = jnp.split(gb, 2, axis=-1)
        x = (1.0 + gamma) * x + beta

        x = nn.Conv(self.channels, (3, 3), padding="SAME")(x)
        x = nn.RMSNorm()(x); x = nn.silu(x)
        x = jnp.mean(x, axis=(1, 2))
        return nn.Dense(self.embed_dim)(x)

Pros

  • Pose can affect different spatial regions differently — preserves the geometric structure that flat FiLM throws away.
  • Ties pose to position via Fourier features — a learned spatial "attention map" for free.
  • Still cheap: a single 1×1 conv produces all per-token (γ, β).

Cons

  • If the 9-dim pose is not directional (just a generic learned embedding from VGGT's camera_head), per-token granularity is wasted capacity.
  • γ, β tensor is now (B, 37, 37, D) — 1369× more modulation params than option 1 — modest VRAM hit but significant gradient noise risk.
  • Requires positional-encoding hyperparameters (frequency band, scale) that affect performance.

Init recipe

Zero-init the per-token Conv1×1: γ = 1 (via 1+Δγ), β = 0 — block is identity. Watch the gradient norm of the per-token modulation in the first 5k steps; if Var(γ) across (h, w) collapses to 0, pose has no spatial structure to exploit and option 1 or 2 is the right call instead.

At a glance

Option Extra params* Compute Modal-balance protection Init recipe Effort
1. Vanilla FiLM ~10k ≈ baseline Multiplicative coupling only γ = 1 + Δγ, β = 0 (zero-init Δ) 1 d
2. Stacked Conv-FiLM ~80k 1.3× baseline Per-layer FiLM; harder to ignore B γi = 1 + Δγi, βi = 0; optional learnable αi 2 d
3. AdaLN-Zero Transformer ~5–8 M 3–5× baseline Per-block γ, β, and output gate α Zero-init all modulation Denses (γ, β, α → 0) 3 d
4. Sigmoid-gated FiLM + hypernet ~80k (+ aux head) ≈ baseline Bounded γ; aux pose-recon loss forces B contribution Zero-init γ, β heads; γ = σ(0) = 0.5 1.5 d
5. Spatial-aware FiLM ~120k 1.2× baseline Per-token coupling — strongest if B has spatial meaning γ = 1 + Δγ, β = 0 (per-token Conv1×1 zero-init) 2 d

*Approx. extra parameters relative to the current single-Dense VGGTEncoder (≈ 4.2M params). Compute scaled to a single forward pass at batch 256.

Suggested ablation order

  1. Land option 1 first as the FiLM baseline — direct A/B comparison vs the current naive flatten-and-project. This is what the issue calls "decide variant(s) to implement first".
  2. Then option 4 if option 1 still shows pose-stream gradient collapse — the auxiliary pose-reconstruction head is the cheapest way to force B contribution.
  3. Then option 2 to test whether multi-layer modulation buys anything on the small 37×37 grid; if yes, this is your default.
  4. Option 5 only if you have evidence (e.g. probing the 9-dim pose) that B encodes directional structure; otherwise its extra capacity is wasted.
  5. Option 3 last, as the "capacity ceiling" experiment. If the simpler variants plateau and you have compute headroom, AdaLN-Zero is the gold-standard reference.

All five share the same VGGTEncoder contract, so the launcher just swaps the registry key. A clean ablation matrix on HM3D ObjectNav val is one config per row — no other code changes needed.

Diagnostics to run for every variant

  • Per-stream gradient norm: log ‖∂L/∂wp‖ and ‖∂L/∂pose‖ separately; ratio should not collapse below ~0.01 if FiLM is doing its job.
  • γ, β statistics: Var(γ) and Var(β) across the batch — if they tend to 0, the FiLM generator has decided to ignore pose.
  • Pose-shuffle ablation: shuffle pose within batch at eval time — performance should drop if B contributes (a clean sanity check inherited from issue #109's last TODO).
  • Pose-zero ablation: replace pose with zeros at eval; compares the "A-only" ceiling.
  • Embedding magnitude: embed.std() ∈ [0.3, 0.7] matches the existing test in test_vggt_encoder.py.
