| | Expected (supervisors) | Actual (implementation) |

| **Dreamer input** | Hybrid: both RGB images **and** VGGT embeddings | VGGT embeddings **only** |

**Decision:** Stay on the **closed-loop** setup for now.

## Hybrid Approach — Requirements

If/when we move to the hybrid approach (Dreamer receives RGB + VGGT embeddings), the following pieces are needed:

- **ZeroMLP** to gate the additional pathway at initialization
- **Ablation over latent space size** — run both a **smaller** and a **larger** latent to see how capacity interacts with the extra modality
- **Decoder must be co-trained** so we can visually verify that the learned representation is correct
- **Replace the linear projection with an MLP** inside the Dreamer itself (the current linear projection is too weak for the hybrid input)

## Issues Raised on the VGGT Path

### 1. VGGT is not invariant

VGGT always operates **relative to the first frame** of the sequence. That means the embeddings are tied to the start observation and are not pose-/start-invariant — flagged as a conceptual concern for the world model.

### 2. Embedding-size mismatch vs. paper

A discrepancy was found between our pipeline and the VGGT paper:

| Source | Patch / pixel size |
|---|---|
| Our WP (current) | **37 × 37 × 3** |
| VGGT paper | **512 × 512 × 3** |

This needs to be reconciled — either by fixing the input pipeline or by clearly documenting why we deviate.
