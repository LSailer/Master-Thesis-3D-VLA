📌 Headline result

Aggregator wins on world-model fidelity (k-step latent rollout MSE ↓ ~20–22%), but WP/CP wins on reward prediction (reward MSE ↓ ~30%). Seed variance is tiny on both — <1% CV on rollout MSE. The two variants disagree on which axis matters.

📎 Caveats and follow-ups

  • Reconstruction NLL is NaN for both — the codebase's R2Dreamer has no observation decoder. The success-criteria table column is structurally empty until a decoder is added (follow-up).
  • Buffer was 400 k transitions, not the originally-planned 500 k (3D-25 reflow). Both variants used the identical (action, reward, done) stream.
  • Dynamics/rep loss not directly comparable across variants — each is computed in its own learned latent. Only the apples-to-apples metrics (k-step rollout MSE, reward MSE) drive the decision.
  • Latent-space metrics on different dim — Aggregator's 3072-d KL/entropy values aren't directly comparable to WP/CP's 4116-d ones either. Don't read too much into the absolute Barlow / encoder-L2 numbers; use them as a sanity check on training dynamics, not as ranking criteria.
  • 3D-46 (PyTorch external R2Dreamer) will give an independent cross-check on the WP/CP side. Relevant if the offline JAX result here is suspected to be implementation-specific.
