Experiment Setup

Environment

  • HM3D ObjectNav v2
  • 145 training scenes
  • 6 goal categories
  • 64x64 RGB only
  • 500 max steps/episode

Agent

  • R2-Dreamer (JAX)
  • RSSM: 2048 deter, 16x32 stoch
  • 4 actions (STOP=no-op)
  • Geodesic-delta reward
  • No goal conditioning

Training

  • 2.4M env steps
  • 5K prefill (random)
  • Train ratio 512
  • LR: 4e-5
  • ~18.6 hours on H100
Hypothesis: Without goal conditioning and with massive scene diversity, the agent will fail to learn. This establishes the lower bound for curriculum experiments.

Episode Metrics

Reward hovers around 0, success rate flat at ~2%, episodes always hit 500 step max.

World Model Losses

KL divergence increases from 2.3 to 10.2 — the RSSM cannot model 145 diverse scene dynamics simultaneously. The world model never converges, so imagination-based policy optimization has no useful signal.

Why the Model Doesn't Learn

1. No Goal Conditioning

The agent sees only RGB — no information about which of the 6 object categories to find. Geodesic-delta reward is noise: moving toward a chair in one episode is wrong for a toilet in the next.

2. Scene Diversity Overwhelms World Model

145 visually distinct houses. The RSSM's KL divergence increases throughout training — it cannot converge on dynamics. Without a working world model, imagination-based planning produces garbage.

3. Sparse Reward Signal

Per-step geodesic deltas are ~0.001. The 10.0 success bonus happens 2.4% of the time by chance. The reward predictor learns "predict ~0" and stops improving (loss: 5.4 → 0.04).

Action distribution: forward 27.6% | left 24.2% | right 27.2% | stop 21.0% — effectively random.

L1 Curriculum — Crash Root Cause

Episode ID Mismatch — Curriculum generator read per-scene content files (local IDs: 0, 1, ..., 49997). Habitat runtime assigns globally-unique IDs when merging 145 files. Filter matched 0 episodes → StopIteration crash after 185s.

Before Fix

  • Generator reads fK2vEV32Lag.json.gz directly
  • Gets local IDs: "7129", "6724", ...
  • Runtime IDs: "22596", "23424", ...
  • 0 episodes matched → crash

After Fix

  • Generator loads via Habitat API
  • Gets globally-unique IDs
  • IDs match runtime exactly
  • 7,499 episodes matched

Next Steps

1. Rerun L1 Curriculum (1 house, chair only)

Bug fixed. L1 isolates whether the world model can learn ObjectNav when scene diversity and goal ambiguity are eliminated. 7,499 training episodes in a single house.

2. Progress Through Curriculum (L2 → L4)

If L1 succeeds: L2 (1 house, 6 goals), L3 (10 houses, 1 goal), L4 (10 houses, 6 goals). Each level adds one axis of complexity.

3. Consider Goal Conditioning

For multi-goal settings (L2+), the agent needs goal information. Options: goal image embedding, category one-hot, or compass-style direction signal.

Key takeaway: This baseline confirms the curriculum approach is necessary. The full-diversity setting is intractable at this model scale without goal conditioning.
